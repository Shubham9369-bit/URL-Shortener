# 🔗 URL Shortener

A simple and full‑stack **URL Shortener App** built with **Node.js, Express, MongoDB (Atlas)** for backend and **React** for frontend.  
Users can shorten long URLs, create **custom short codes**, copy links, track clicks, and redirect easily.

---

## 🚀 Features
- Shorten long URLs into short links
- Custom short code support (e.g., `/shubham` instead of random code)
- Click tracking (counts how many times a link was opened)
- Copy to clipboard button
- Redirect to original URL
- Responsive React frontend with modern UI

---

## 🛠️ Tech Stack
- **Frontend**: React, CSS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB Atlas (Cloud)
- **Deployment**: Render (Backend), Netlify (Frontend)
